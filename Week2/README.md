# Week2_Vulnerability Assessment and Threat Modeling

## Files
- `Week2_Vulnerability_Assessment.docx` — report with vulnerability analysis, STRIDE-informed threat model, worked IDOR example, prioritized risk register, mitigation plan, metrics and references.
- `Week2_Threat_Model_Diagram.png` — hypothetical architecture and attack paths.

## Scope and ethics
This is a desk-based hypothetical assessment. No real government portal or production system was scanned, probed or tested. Risk scores are illustrative, not measured findings. Any real assessment requires explicit written authorization and a defined scope.
